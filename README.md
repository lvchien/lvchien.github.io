# Le Van Chien — Multi-page Academic Website

Static GitHub Pages website with five pages:

- `index.html` — Home
- `research.html` — Research, awards, grants, and invited talks
- `publications.html` — Filterable publications
- `about.html` — Experience, education, and profiles
- `contact.html` — Contact information

## Publish on GitHub Pages

Upload every file and the `assets` folder to the root of:

`lvchien/lvchien.github.io`

Then open **Settings → Pages**, select **Deploy from a branch**, choose
**main** and **/(root)**, and save.

The published site will be available at:

https://lvchien.github.io
